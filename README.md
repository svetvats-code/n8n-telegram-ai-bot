# Умный Telegram-бот с AI-агентом и Google Таблицами (на базе n8n)
## 📌 Описание проекта
Этот репозиторий содержит сценарий (workflow) для платформы автоматизации **n8n**. 
Проект представляет собой Telegram-бота на базе искусственного интеллекта, который общается с пользователем, запоминает контекст беседы и умеет автоматически структурировать входящую информацию, записывая её в Google Таблицы.
## 🛠 Стек технологий
* **n8n** — ядро автоматизации, связывающее все сервисы воедино.
* **Telegram API** — пользовательский интерфейс (триггеры и отправка сообщений).
* **OpenRouter (LLM)** — нейросеть (AI Agent) для ведения диалога и логической обработки текста.
* **Google Sheets API** — инструмент (Tool) для сохранения структурированных данных (идей, задач, заметок).
## ✨ Основной функционал
1. **AI-агент с инструментами:** Бот не использует жесткие скрипты. Нейросеть сама принимает решение, когда нужно просто ответить пользователю, а когда — вызвать инструмент для записи в базу данных.
2. **Долгосрочная память (Window Buffer Memory):** Агент использует сессионную память с привязкой к ID чата, что позволяет ему помнить контекст предыдущих сообщений.
3. **Запись данных:** При получении команды (например, "Запиши идею: купить корм коту"), ИИ записывает данные в таблицу.
## 🚀 Как развернуть проект у себя
1. Скачайте файл сценария `.json` из этого репозитория.
2. В вашем инстансе n8n в правом верхнем углу меню выберите `Import from file`.
3. Загрузите файл на холст.
4. Подключите собственные учетные данные (Credentials) для Telegram, OpenRouter и сервисного аккаунта Google Cloud.
