# AI-Пайплайн для записи на встречи (Внутренний ассистент)

## 📌 Описание проекта
Автоматизированная система для извлечения структурированных данных из свободного текста. 
Бот работает как **внутренний корпоративный ассистент**. Сотрудник пересылает в бота сообщения от клиентов или отправляет голосовые заметки. Бот валидирует наличие всех необходимых данных (дата, время, тема) и автоматически формирует запись в базе данных, избавляя персонал от ручного заполнения таблиц.

## 🛠 Архитектура и стек
* **n8n** — оркестрация потока данных.
* **OpenRouter (LLM)** — логическое ядро агента.
* **Structured Output Parser** — жесткий контроль формата ответа ИИ (генерация строгого JSON по заданной схеме).
* **Узел If (Логическое ветвление)** — проверка полноты данных. Разделение потока на успешную запись и возврат ошибки сотруднику для уточнения деталей.
* **Google Sheets API** — база данных.

## ✨ Бизнес-логика (Как это работает)
1. **Парсинг и нормализация:** ИИ переводит абстрактные фразы менеджера ("в следующий понедельник", "завтра после обеда") в строгий формат YYYY-MM-DD и HH:MM, используя проброс системного времени сервера.
2. **Защита от человеческого фактора:** Если сотрудник забыл передать боту тему или время, ИИ не пропускает "мусорные" данные в базу. Сценарий идет по красной ветке (False), и бот возвращает сотруднику запрос на уточнение.
3. **Бесшовная запись:** Полностью валидные данные автоматически отправляются в Google Таблицы.
