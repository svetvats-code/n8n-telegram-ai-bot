# AI-Пайплайн для записи на встречи (n8n + Telegram)

## 📌 Описание проекта
Автоматизированная система (пайплайн) для извлечения структурированных данных из свободного текста. 
Бот принимает голосовые или текстовые запросы пользователя, валидирует наличие всех необходимых данных (дата, время, тема) и автоматически формирует запись в базе данных. 

## 🛠 Архитектура и стек
* **n8n** — оркестрация потока данных.
* **OpenRouter (LLM)** — логическое ядро агента.
* **Structured Output Parser** — жесткий контроль формата ответа ИИ (генерация строгого JSON по заданной схеме).
* **Узел If (Логическое ветвление)** — проверка полноты данных. Разделение потока на успешную запись и возврат ошибки пользователю.
* **Google Sheets API** — база данных.

## ✨ Бизнес-логика (Как это работает)
1. **Парсинг и нормализация:** ИИ переводит абстрактные понятия ("в следующий понедельник", "завтра после обеда") в строгий формат YYYY-MM-DD и HH:MM, используя проброс системного времени сервера.
2. **Валидация данных:** Если пользователь забыл указать тему или время, ИИ не пропускает "мусорные" данные в базу, а возвращает запрос на уточнение.
3. **Бесшовная запись:** Полностью валидные данные автоматически отправляются в Google Таблицы.
